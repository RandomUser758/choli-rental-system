# Choli Rental Manager

A web-based choli rental management system built with HTML, CSS, and JavaScript.

## Features
- 📊 Dashboard with business overview
- 📦 Inventory management
- 📅 Availability checking (auto-blocks pickup to return dates)
- 📝 Booking management
- 👥 Customer management
- 🔄 Return tracking
- 📈 Reports & analytics

## Tech Stack
- Pure HTML, CSS, JavaScript
- localStorage for data persistence
- No backend required
